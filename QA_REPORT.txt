Cursor Quest Choices v2.3.5 - Regression QA

Primary fix
- Replaced Hero's Call Board detection based on IsShown() with effective visibility checks.
- A child frame can report IsShown() while its parent is hidden; that stale state was blocking every later normal NPC quest.
- Board blocking is now stateless and clears immediately when the board is not truly visible.

Normal quest path verified
- GOSSIP_SHOW reaches SelectNextGossipAutoAction when the board is not visible.
- QUEST_GREETING reaches SelectNextGreetingAutoAction when the board is not visible.
- QUEST_DETAIL reaches AcceptQuest without requiring UnitExists("npc") or a specific panel global.
- QUEST_PROGRESS, QUEST_COMPLETE, QUEST_ACCEPT_CONFIRM, and QUEST_FINISHED are not held by stale board state.
- Multi-quest continuation remains bounded and retains duplicate-action protection.

Other regression checks
- Shift pause remains independent.
- Manual reward picker remains available when automation is paused.
- Native merchant frame still captures one opening anchor and defaults left of the cursor.
- Merchant purchases and MERCHANT_UPDATE reuse the original anchor.
- Cursor interaction panel remains hidden while the actual Hero's Call Board is visibly open.
- Legacy AutoQuestMaster neutralization retained.

Validation
- Lua parsed successfully with luaparser.
- Archive contains one executable Lua file.
- ZIP integrity tested successfully.
